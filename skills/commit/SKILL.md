# commit

- If the project has a defined format for commit messages or pull requests (contribution docs, existing commit history, pull request templates), follow it. If not, end the subject and body of a commit message, and the title and body of a pull request, with a nominal ending such as "~를 추출" or "~를 저장", not a declarative ending such as "~한다" or "~합니다".
